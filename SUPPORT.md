# Support

**Language / Idioma: English · [Español](SUPPORT.es.md)**

This project is public and MIT licensed. **0.6.0-rc.2 is a release candidate**; host integration remains under field test.

- Installation, upgrades, removals and limitations: [INSTALL.md](docs/INSTALL.md).
- Troubleshooting without revealing local paths or settings: run `npm run doctor`.
- Non-security bug reports: [GitHub Issues](https://github.com/csecurh/quota-pilot/issues/new/choose), with sanitized logs and synthetic data.
- Security flaws: follow [SECURITY.md](SECURITY.md) privately; never disclose exploit details or real credentials in an issue.

Support is best-effort; no paid SLA or guaranteed host compatibility is provided. This plugin is not an official OpenAI or Anthropic product.
